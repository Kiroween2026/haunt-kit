2026-11-17 | Yadnesh | Property-based testing | The round-trip property passed with the first draft's 64-sample batch limit, because fast-check generates small arrays by default. A targeted worst-case check showed 64 samples of max-length numbers are about 21 KB, over the 16 KB limit, so a batch could pass the schema and still fail encode. Lowered the limit to 32 (about 10.7 KB) and added a property test that a full worst-case batch always fits.
2026-11-17 | Yadnesh | Property-based testing | Added a "no player spoofing" property: any playerId a phone puts on sensor_frames or gesture is dropped by decode, so the relay can only forward input under the sender's own id.

Both were caught, but the first run showed two weak spots: the test harness kept sending from sockets the relay had already closed, and waits up to 90 s meant almost no rejoin happened inside the 60 s grace window. Fixed the harness, added waits around the 60 s and 120 s limits, and raised runs to 400.
2026-11-19 | Yadnesh | Vibe chat | Ran the same 7-step smoke test against the Node relay and against the Cloudflare Durable Object in `wrangler dev`. Both passed: create, join, frames stamped with the sender's id, ui, phone rejoin with the same id and color, host resume, unknown room.

2026-11-19 | Yadnesh | Property-based testing | The protocol round-trip property failed in CI with a new random seed: a gesture with data {"**proto**": 0} decoded as {} because zod drops that key to block prototype pollution. Added explicit tests for the counterexample.
